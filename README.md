## Visão geral

Repositório de exercícios, práticas guiadas e pequenos projetos em Java. O conteúdo reúne lógica de programação, orientação a objetos e atividades do MOOC de Java da Universidade de Helsinki.

Cada diretório representa uma etapa ou tema de estudo; este repositório não é uma aplicação única.

## Trilha de estudos

| Diretório | Conteúdo |
| --- | --- |
| [GameOfThronesPOO](src/GameOfThronesPOO/) | Exercícios de orientação a objetos com temática de Game of Thrones. |
| [HarryPotterPoo](src/HarryPotterPoo/) | Modelagem e prática de POO com personagens. |
| [MoocHelsinki](src/MoocHelsinki/) | Atividades do curso MOOC.fi de Java. |
| [TreinoJavaIniciante](src/TreinoJavaIniciante/) | Prática dos fundamentos da linguagem. |
| [TreinoJavaIntermediario](src/TreinoJavaIntermediario/) | Exercícios de aprofundamento em Java. |

## Como executar

```bash
git clone https://github.com/vineog23-boop/java-studies-portfolio.git
cd java-studies-portfolio
```

Abra a pasta na IDE e escolha o exercício desejado. Configure um JDK compatível com aquele módulo e execute sua classe com `main`.

Os exercícios do MOOC podem ter `pom.xml` e testes próprios. Nesse caso, abra o diretório específico como projeto Maven e use as configurações fornecidas por ele. Não há um build único para toda a coleção.

## Como navegar

1. Comece por `TreinoJavaIniciante` para revisar sintaxe e lógica.
2. Explore os projetos temáticos para acompanhar a modelagem de objetos.
3. Consulte `MoocHelsinki` e `TreinoJavaIntermediario` conforme o assunto estudado.

A organização facilita acompanhar a evolução dos estudos. Os projetos de API REST completos ficam em repositórios próprios no [meu perfil](https://github.com/vineog23-boop).

## Testes

Parte dos exercícios do MOOC inclui testes locais. Execute-os dentro do respectivo módulo; não existe uma suíte global nem uma métrica única de cobertura para esta coleção.
